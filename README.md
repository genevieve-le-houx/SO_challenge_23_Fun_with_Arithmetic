# Stackoverflow challenge #23: Fun with Arithmetic 

This is my submission to Stackoverflow challenge #23: Fun with Arithmetic 

https://stackoverflow.com/beta/challenges/80003558/challenge-23-fun-with-arithmetic

The goal of the challenge is to compute from a list a number (numbers.txt) :
- The mean
- The median
- The mode
- The frequency of each digits
- The even sum
- The odd sum

# Execution

The code is done using Python 3.14.2. To execute, simply run main.py. numpy library is needed.
